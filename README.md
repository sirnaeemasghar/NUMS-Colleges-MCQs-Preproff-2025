# NUMS Colleges MCQs Preproff 2025

A single study hub for the three NUMS pre-prof MCQ block websites.

## Public website

The site is published from `docs/` through GitHub Pages. Opening the home page shows links to Block 1, Block 2, and Block 3.

## Update the website

Run `python3 build_site.py` from this folder after editing either React block. This rebuilds both React apps and refreshes `docs/`. Commit and push the changed files to `main`; GitHub Pages then publishes the new `docs/` content.

## Use offline on a Mac

Double-click `Open NUMS Pre-Prof MCQs.command`. It starts the three local pages and opens the study hub in your browser. Keep the Terminal window open while using it.
